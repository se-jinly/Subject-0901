다음 순서로 확인하고, 결과를 3줄 이내로 보고한다.

1. Unity MCP로 콘솔을 확인한다. 에러와 경고만 본다.
2. 에러가 있으면 원인을 고치고 1번을 다시 한다. 같은 에러를 2번 고쳐도 남으면 멈추고 보고한다.
3. 이번 작업과 관련된 테스트가 있으면 실행하고 결과를 보고한다.
4. 이번 작업에서 디버그용으로 추가한 Debug.Log가 남아 있으면 알려준다.

보고 형식:
- 컴파일: 성공 / 실패 (에러 내용)
- 경고: 없음 / 있음 (요약)
- 남은 디버그 로그: 없음 / 파일명

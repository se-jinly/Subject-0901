기능을 마무리한다. 순서대로 진행:

1. /check 절차로 컴파일 에러와 경고를 확인한다. 에러가 있으면 여기서 멈추고 보고한다.
2. 이번 작업에서 디버그용으로 추가한 Debug.Log를 지운다.
3. docs/progress.md를 최신 상태로 덮어쓴다 (현재 상태 / 최근 한 일 / 다음 할 일, 10줄 이내).
4. 새 에셋(그림, 사운드 등)을 추가했다면 docs/ai-usage.md에 한 줄 기록한다.
5. 새 스크립트를 만들었거나 흐름이 바뀌었다면 docs/architecture.md의 해당 부분만 고친다.
6. 바꾼 파일 목록과 변경 내용을 3줄 이내로 요약한다.
7. 커밋할지 물어본다. 커밋 메시지는 한국어로 제안한다. 푸시는 하지 않는다.

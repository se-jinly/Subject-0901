## 한 줄 소개
주인공이 혼자서 적국을 때려부수는 핵 앤 슬래시 게임.

## 기본 정보
- 장르: 3D 핵 앤 슬래시
- 목표: 출시
- 주인공: [이름, 성격, 혼자 싸우는 이유]
- 적국: [나라 이름, 분위기]
- 아트 방향: [예: 로우폴리 / 카툰 / 사실적]

## 핵심 루프 (확인 필요)
웨이브 전투 → 웨이브 클리어 보상 → [보상으로 무엇이 강해지는지] → 다음 웨이브 → 보스

## 현재 구현된 것
- 웨이브 진행
- 웨이브 클리어 시 보상
- 보스 (BossEnemy)
- 기본 전투 (근접 적, 원거리 적)

## 4주 목표: 5분 플레이 데모
"처음 켜서 끝날 때까지 5분 동안 진짜 게임처럼 플레이되는 버전"

데모에 필요한 것 (제안: 직접 고르고, 빼고, 추가하세요)
- [ ] 시작 화면 → 게임 → 결과 화면까지 이어지는 흐름
- [ ] 게임 오버와 다시 하기
- [ ] 체력, 웨이브 정보 같은 기본 UI
- [ ] 타격감 (히트 이펙트, 효과음, 화면 흔들림 등)
- [ ] 웨이브 [몇]개 + 보스 1마리로 약 5분 분량
- [ ] 보상 선택이 다음 전투에서 체감되게
- [ ] 조작 안내 (키 안내 또는 간단한 튜토리얼)

## 주차별 계획 (제안)
- 1주차: 게임 흐름 완성 (시작 → 웨이브 → 보스 → 결과 / 게임 오버)
- 2주차: 전투 다듬기 (타격감, 적 패턴, 보상 효과)
- 3주차: 분량 채우기 (웨이브 구성, 밸런스), UI와 사운드
- 4주차: 버그 수정, 친구 플레이 테스트, 빌드
